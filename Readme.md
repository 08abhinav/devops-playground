# DevOps Playground

A hands-on repository for building, experimenting, and documenting real-world DevOps projects and workflows.

## About

This repository contains **10 practical DevOps projects** focused on learning and implementing real-world DevOps practices, infrastructure workflows, automation, deployment strategies, monitoring, scalability, and system reliability.

All projects are built and tested using **AWS** as the primary cloud provider.
The goal of this repository is to:
- Practice real-world DevOps concepts
- Build production-style project setups
- Document complete workflows and architecture
- Learn infrastructure and deployment patterns
- Improve troubleshooting and operational skills

---

## Projects Included

### Project 1: Setup a Static Website Using Nginx
- Configure and host a static website using Nginx web server.

### Project 2: Setup Multiple Static Websites on a Single Server Using Nginx Virtual Hosts
- Configure multiple websites on a single server using Nginx virtual host configuration.

### Project 3: Setup Load Balancing for Static Website Using Nginx
- Implement load balancing between multiple backend servers using Nginx.

### Project 4: Setup WordPress Website Using LAMP Stack
- Deploy a WordPress application using Linux, Apache, MySQL, and PHP.
